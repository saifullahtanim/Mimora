This free fake disk format screen makes it look like the hard drive is being wiped. Launch it fullscreen and a Windows Command Prompt opens on the real Microsoft Windows [Version 10.0.19045.4046] banner, types format c:, prints the genuine WARNING, ALL DATA ON NON-REMOVABLE DISK DRIVE C: WILL BE LOST! message, and waits at the Proceed with Format (Y/N)? prompt — so the format appears to start the moment someone touches the keyboard. Typing N does not save them: the screen replies that the operation cannot be aborted and formats anyway. There is also a modern Windows “Formatting Local Disk (C:)” dialog whose Cancel button politely refuses to cancel. Nothing is formatted, nothing is deleted, and ESC ends the whole thing instantly.





What the fake disk format prank does





The prank recreates the most alarming screen in computing: a disk being erased, with no obvious way to stop it. The command is typed out character by character at a C:\Users\User> prompt, the file-system line and the warning appear, and once the format begins a percent counter climbs in place exactly as format.com does. When it reaches 100% the screen prints the completion report — file system structures created, format complete, total and available disk space, a volume serial number — and returns to a blinking prompt on an apparently empty disk. Tick the retro option and it becomes an MS-DOS machine instead, with phosphor glow, scanlines, a bare C:\> prompt and the old head/cylinder/sector readout that made a fake format prank so recognisable in the first place.





Two styles: Command Prompt format c: or the Windows dialog





    

  • Command Prompt — format c: A full-screen cmd.exe window: the Windows version banner, a C:\Users\User> prompt, the typed command, and the format running as raw text with no window to close and no way out. Tick “Retro CRT / MS-DOS look” and the same sequence becomes an old MS-DOS terminal — glowing phosphor text, scanlines, and the DOS-era completion report.
    • 



  • Windows — format dialog Opens with a warning that Windows has detected a problem with the drive and it must be formatted. Both buttons lead to the same place: “Format drive” starts it, and Cancel is told the operation cannot be postponed before it starts anyway. Then a “Formatting Local Disk (C:)” progress dialog fills on a blue desktop. This is the more believable style on a modern PC.
    • 






Both styles run the same fake disk format underneath, at whatever speed you choose. Pick DOS for drama and Windows for plausibility.

The Y/N prompt: the walk-away setup





The Proceed with Format (Y/N)? prompt is the best part of the fake disk format, because it shifts the blame. The screen sits there quietly, warning that all data on drive C: will be lost, and nothing happens until a key is pressed — at which point the format starts, apparently because they pressed it.





A worked example. Say you want a friend to think they wiped their own laptop:





    

  1. Open this page on their machine while they are away and choose the Command Prompt style — a bare console is far more frightening than a friendly dialog.
    2. 



  2. Keep the Y/N prompt ticked and set the speed to Slow, so the format runs long enough for panic to set in.
    3.

    4. 



  4. Watch them press a key to see what happens — and watch the format start. If they think quickly and press N, they get told the operation cannot be aborted and it starts anyway. The Windows style works the same way: Cancel formats the drive just as surely as Format drive does.
    5. 



  5. End it quickly with ESC. The desktop is untouched, which is the moment the joke turns from cruel to funny.

Why the Cancel button does not work





Neither button in the Windows style is an escape route, and that is the whole joke. The opening dialog offers Format drive and Cancel; choosing Cancel simply answers that the operation cannot be postponed and the drive is unusable in its current state, then formats it anyway. Once the progress bar is moving, Cancel produces a second refusal — Windows cannot cancel formatting while it is in progress — and dismissing it puts you back at the dialog with the fake disk format still running. A progress bar alone is just something to watch; a progress bar with buttons that will not save you is something to panic about. ESC always ends it for real.





Choosing the drive letter





The drive letter changes how frightening the prank is. C: is the system drive on a Windows PC — formatting it would erase Windows itself along with every document, photo, and game on the machine, which is why “format c:” became shorthand for total destruction. D: and E: usually mean a second internal disk, an external drive, or a USB stick, so a fake hard drive format on those letters reads as bad but survivable. If you are pranking someone who genuinely keeps irreplaceable work on one machine, the gentler letter is the kinder choice.





Why use a browser-based fake disk format?





Most “format prank” results are either videos you have to play at exactly the right moment or downloads that ask to run a program on the machine — which is a strange thing to install in the name of a joke about data loss. This one is a single web page. It loads instantly, installs nothing, and disappears the moment the tab closes.





Being live rather than recorded matters here more than in most pranks: the prompt genuinely waits for a keypress, the Cancel button genuinely refuses, and the format lasts exactly as long as you set. A video cannot react to anything the victim does, and that is usually what gives it away.





Is the fake disk format safe?





Completely. It is an animation made of HTML, CSS, and JavaScript running inside a browser tab. No drive is formatted, no partition table is touched, and not one file is read, written, or deleted. A web page cannot format a disk — that needs administrator rights and a real disk utility — and this one never asks for any permission at all. Every byte count, sector number, volume serial, and percentage on the screen is invented by the page for show.





Because there are no downloads and no executables, antivirus software treats this like any other website. Press ESC and everything stops at once, with nothing left running in the background and nothing to uninstall.





Fake disk format vs. a real format





A real format runs from a disk utility, an installer, or an elevated command prompt — never from a web page — and it demands administrator confirmation before it touches anything. It also survives a reboot: a genuinely formatted drive is still empty when the machine restarts. This fake format prank does none of that. It lives in a browser tab, and one press of ESC restores a completely normal desktop with every file exactly where it was.





That is the reassurance to offer anyone who falls for it. It is also worth remembering in reverse: if a web page ever tells you it is formatting your disk, it is lying — either as a joke like this one, or as a scare tactic trying to make you install something.





Tips for a believable format prank





    

  • Always go fullscreen. A visible address bar ends the illusion immediately — the DOS screen especially only works edge to edge.
    • 



  • Match the style to the machine. The Windows dialog looks right on a current laptop; the Command Prompt is scarier, and the retro CRT look suits an old PC or a joke about ancient hardware.
    • 



  • Use Slow or Normal speed. A fake disk format that finishes in fifteen seconds looks like an animation; a slow one looks like work being done.
    • 



  • Leave it at the Y/N prompt if you want the victim to trigger it themselves — much funnier than starting it in front of them.
    • 



  • Leave the retro CRT option off unless you want the MS-DOS flavour — plain cmd.exe is what a modern Windows PC actually looks like, so it is the more believable of the two.
    • 






Prank responsibly





A fake disk format is one of the harsher jokes you can play on someone who works on a computer. People keep years of photos, coursework, and unbacked-up projects on a single machine, and a genuine belief that it is all going means real distress — some will yank the power cable, which on a real system is how you actually cause damage. Keep this to people who will laugh, stay in the room, and end it with ESC within a minute. Never use it on a stranger, on someone already anxious about their computer, or as a set-up for selling “recovery” help.





Does the fake disk format work on Mac or Linux?





It runs in any modern browser, so the page itself works on Windows, macOS, Linux, ChromeOS, Android, and iOS. Whether it is convincing there is a different question. Drive letters and the format c: command are Windows and MS-DOS ideas — a Mac has no C: drive, and neither does a phone — so a fake disk format on those devices reads as a joke almost immediately to anyone who knows the machine. On a Mac, Linux box, or phone, a prank screen built for that platform will land better.





The one exception is a shared or public computer where nobody is sure what is running. In front of an audience that is not paying close attention, a black screen full of scrolling format output does the job on almost any hardware, because the text is what people recognise, not the operating system underneath.
